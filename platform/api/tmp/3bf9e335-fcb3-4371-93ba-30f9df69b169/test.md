## Варіант 1

**1.** Відмітити все, що є однією правильною лексемою:

- ( 1 ) ++
- ( 2 ) 'c'
- ( 3 ) """1"2"""
- ( 4 ) -1.5

**2.** Відмітити все, що є однією правильною лексемою:

- ( 1 ) **
- ( 2 ) /
- ( 3 ) <=
- ( 4 ) 3a

**3.** Відмітити все, що є коректним оператором С++:

- ( 1 ) x=*2
- ( 2 ) x,y,z=z,z,y
- ( 3 ) r=('N'>'5')
- ( 4 ) 'a'a'

**4.** Відмітити все, що є коректним оператором С++:

- ( 1 ) double n.m;
- ( 2 ) x=int(4);
- ( 3 ) char c=13;
- ( 4 ) cout<<(3<>5);
